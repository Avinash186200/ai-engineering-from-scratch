# AI Engineering from Scratch with Avinash

Code for the YouTube series **AI Engineering from Scratch with Avinash**: ten days that go from
"what is a token" to a tested, containerised AI assistant, plus interview practice.

Every example uses one running project: a **research assistant for Indian mutual funds**.
All fund data here is **synthetic** (generated by `data/make_data.py`). Nothing in this repo is
investment advice, and no real fund is described.

No API key is needed. Every LLM script runs with a deterministic `FakeLLM` by default.
Add `--real` (and set `ANTHROPIC_API_KEY`) to use Claude through the same adapter.

## Setup

```bash
python -m venv .venv
source .venv/bin/activate          # Windows: .venv\Scripts\activate
pip install -r requirements.txt
python data/make_data.py           # regenerates data/funds.csv (already included)
```

Python 3.11. Run every command from the repo root.

## Notes per day

- **core/fund_model.py**: `rank_funds(as_of=None, top_n=5)` returns
  `{"as_of": ..., "top": [{"rank", "fund", "predicted_return"}]}`, or `{"error": ...}`
  for a bad date, a weekend, or a date outside the data. Also `fund_info` and `lookup_term`.
- **Day 2**: `system_prompt.md` is the assistant's system prompt. `--real` sends it to Claude.
- **Day 3**: try `python day03_agents/agent.py --ask "top 3 funds on 2024-11-04"`.
- **Day 4**: the server speaks MCP over stdio; the client starts it as a subprocess.
  To use it from an MCP host, point the host at `python day04_mcp/fund_mcp_server.py`.
  Works with `mcp` 1.x (`FastMCP`) and 2.x (renamed `MCPServer`).
- **Day 5**: uses `sentence-transformers` if installed, else a hashed bag-of-words
  embedder (no downloads). `python day05_rag/mini_rag.py "What is an exit load?"`.
- **Day 6**: exits with code 1 if the pass rate is below `--min-pass` (default 0.9).
- **Day 7**: compares leaky shuffled K-fold with walk-forward and purged + embargoed CV
  (about 30-60 seconds). The metrics are illustrative: the data is synthetic.
- **Day 8**: run the server with `uvicorn app:app --app-dir day08_production --port 8000`.
  Docker: `docker build -f day08_production/Dockerfile -t fund-assistant .` from the repo root.

## Using real Claude

```bash
pip install anthropic
export ANTHROPIC_API_KEY=...       # never commit keys; .env is git-ignored
python day03_agents/agent.py --real
```

The model name is set once in `core/llm.py`.
